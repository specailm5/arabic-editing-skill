# مهارة التحرير والنقد والتدقيق

> مبنية على **«الأسلوب»** لأحمد الشايب، و**«أصول النقد الأدبي»** لأحمد الشايب، و**«معجم الصواب اللغوي»** لأحمد مختار عمر.
> ومسنودة بـ**`arabic-writing-skill`** في اللغة ونبذ العَرَنْجِيَّة، وبـ**`arabic-grammar-skill`** في التصحيح النحوي.

> **تنبيه:** هذه المهارة **للتحرير والنقد والتدقيق**، لا للكتابة من الصفر. وهي **لا تُعيد كتابة النص صامتة**؛ بل تُصدر تقريراً، ثم تُعدّل بطبقات، وتحفظ صوت الكاتب.

---

## ٠. قبل أن تبدأ: ستة أسئلة

| السؤال | لماذا؟ | إن لم يُجب |
| :--- | :--- | :--- |
| **١. ما نوع النص؟** (مقال / بحث / قصة / خطبة / خبر / رسالة / ترجمة) | يحدد معايير التحرير | افترض مقالاً |
| **٢. ما مستوى التحرير؟** (بنيوي / فقرة / جملة / تدقيق / مراجع / شامل) | يحدد عمق التدخل | اسأل، ولا تخلط |
| **٣. ما الجمهور؟** | يحدد اللغة والمثال | جمهور عام |
| **٤. ما الغرض؟** (إفهام / إقناع / تأثير / إمتاع) | يحدد الوضوح/القوة/الجمال | إفهام |
| **٥. هل أحفظ صوت الكاتب؟** | يحدد حجم التعديل | نعم، افتراضاً |
| **٦. هل تريد تقريراً أم نصاً معدّلاً أم كليهما؟** | يحدد المخرج | تقرير + نص |

**أسئلة تكميلية:**
- هل هناك دليل أسلوبي أو مصطلحات موحدة؟
- هل هناك أرقام/أسماء/مراجع تحتاج تحققاً؟
- هل النص عاميّ مقصود؟
- هل هناك حساسيات أو خطوط حمراء؟
- ما الحد الأقصى للتدخل (صامت/مشروح/إعادة بناء)؟

---

## ١. المبادئ العشرة

1. **صوت الكاتب أولاً:** التحرير يحسّن النص، لا يحوّله إلى نصك.
2. **أقل تدخل:** غيّر ما يحتاج التغيير، واترك ما هو جائز.
3. **كل تعديل بسببه:** لا تقل «أفضل» بلا معيار.
4. **الطبقات:** لا تخلط البنيوي باللغوي بالتدقيقي.
5. **المعنى مقدّم:** لا تُحسّن اللفظ على حساب المعنى.
6. **الوضوح:** ما يحتاج شرحاً من القارئ فقد فشل.
7. **الوحدة:** موضوع واحد، فكرة جامعة، بناء مترابط.
8. **الإنصاف:** انقد النص لا الشخص.
9. **التحقق:** لا تُقرّ رقماً أو اسماً أو مرجعاً بلا مصدر.
10. **لا تجامل:** المجاملة تُفسد النص وتُضلّ القارئ.

## ٢. مستويات التحرير الخمسة

| المستوى | ما يعالجه | مثال |
| :--- | :--- | :--- |
| **١. التحرير البنيوي** | الفكرة، البناء، الترتيب، الحجة، الجمهور | مقال بلا أطروحة |
| **٢. تحرير الفقرة** | وحدة الفكرة، الترابط، الطول، الانتقال | فقرة تجمع ثلاث أفكار |
| **٣. تحرير الجملة** | الطول، الترتيب، الوصل، الحشو، الإيقاع | جملة من ٦٠ كلمة |
| **٤. التدقيق اللغوي** | النحو، الإملاء، الترقيم، الاتساق | همزة، فاصلة، مطابقة |
| **٥. التحقق** | المراجع، الأرقام، الأسماء، التواريخ | «قال الباحث...» بلا مصدر |

**قاعدة:** ابدأ من الأعلى إلى الأدنى؛ لا تُدقّق فاصلة في فقرة سيُحذف نصفها.

---

## ٣. مسار العمل

```text
① اقرأ النص كاملاً بلا حكم
        ↓
② حدد النوع والغرض والجمهور
        ↓
③ شخّص المستويات الخمسة
        ↓
④ اكتب تقرير التحرير (موضع/مشكلة/خطورة/اقتراح/سبب)
        ↓
⑤ عدّل طبقة طبقة
        ↓
⑥ دقّق: المعنى + اللغة + المراجع + الصوت
        ↓
⑦ سلّم: تقرير + نص + قائمة تغييرات
```

### ٣.١ القراءة الأولى

- اقرأ النص كاملاً دون توقف.
- لا تُصلح شيئاً في القراءة الأولى.
- اسأل: ما الفكرة؟ ما الغرض؟ ما الجمهور؟ ما الصوت؟

### ٣.٢ التشخيص

| المستوى | السؤال |
| :--- | :--- |
| **بنيوي** | هل هناك أطروحة؟ هل البناء يخدمها؟ |
| **فقرة** | هل كل فقرة فكرة واحدة؟ هل تترابط؟ |
| **جملة** | هل الجملة واضحة؟ هل فيها حشو؟ |
| **كلمة** | هل الكلمة دقيقة؟ هل هي مبتذلة/غريبة؟ |
| **ميكانيكا** | نحو، إملاء، ترقيم، اتساق |
| **مراجع** | هل كل دعوى لها مصدر؟ |

---

## ٤. التحرير البنيوي

### ٤.١ الأطروحة

**السؤال:** ما الجملة التي يريد الكاتب إثباتها؟
**إن غابت:** اقترح أطروحة، ولا تُعد كتابة النص قبل موافقة الكاتب.
**إن تعددت:** اختر أطروحة واحدة، وأجّل الباقي.

### ٤.٢ البناء

| النموذج | متى |
| :--- | :--- |
| **مقدمة → عرض → خاتمة** | مقال/بحث قصير |
| **مشكلة → تحليل → حل** | مقال إصلاحي |
| **دعوى → دليل → رد → ترجيح** | بحث/مقال حجاجي |
| **قصة → عبرة** | خطبة/مقال وعظي |
| **سؤال → أجوبة → تركيب** | مقال فكري |

**قاعدة:** كل قسم يجب أن يخدم الأطروحة، وإلا حُذف.

### ٤.٣ ترتيب الأقسام

- ابدأ بالأهم للقارئ، لا بالأهم لك.
- قدّم السياق قبل التفصيل.
- اجعل كل قسم نتيجة لما قبله.
- اختم بما تريد أن يبقى.

### ٤.٤ الحجة

- هل الدعوى واضحة؟
- هل الدليل كافٍ؟
- هل هناك دعاوى بلا دليل؟
- هل هناك مغالطات؟
- هل عُرض الرأي المخالف ثم رُدّ عليه؟

### ٤.٥ الجمهور

- ما مستوى القارئ؟
- ما الذي يعرفه مسبقاً؟
- ما الذي يحتاج شرحاً؟
- ما الذي قد يُغضبه؟

---

## ٥. تحرير الفقرة

### ٥.١ وحدة الفكرة

**القاعدة:** فقرة واحدة = فكرة واحدة.
**إن تعدّدت:** قسّمها.
**إن خلت:** احذفها أو ادمجها.

### ٥.٢ الترابط

- **الربط اللفظي:** الضمائر، أدوات الربط، التكرار المقصود.
- **الربط المعنوي:** السبب/النتيجة، العام/الخاص، المقارنة.
- **الانتقال:** جملة تنبيه عند تغيير الموضوع.

**قاعدة:** لا تحذف رابطاً يحتاجه القارئ.

### ٥.٣ الطول

- **الفقرة الطويلة:** تقطع النفس، وتُضيع الفكرة.
- **الفقرة القصيرة:** قد تُشتت.
- **الطول المناسب:** ٣–٦ جمل للمقال، وأكثر للبحث.

### ٥.٤ اختبار الفقرة

- [ ] فكرة واحدة.
- [ ] جملة موضوعية.
- [ ] جمل داعمة.
- [ ] ربط.
- [ ] انتقال.
- [ ] خاتمة جزئية.

---

## ٦. تحرير الجملة

### ٦.١ الطول

| الطول | الأثر | العلاج |
| :--- | :--- | :--- |
| **قصيرة جداً** | تقطع الإيقاع | ادمج |
| **متوسطة** | واضحة | اترك |
| **طويلة** | تُرهق القارئ | قسّم |

**قاعدة:** إذا احتجت إلى نفس طويل، فقسّم.

### ٦.٢ الترتيب

- قدّم الفاعل والفعل.
- لا تفصل بين المتلازمين.
- اجعل المعلوم قبل المجهول.
- اجعل الأهم في نهاية الجملة.

### ٦.٣ الوصل والفصل

- **الوصل:** إذا كان بين الجملتين جامع.
- **الفصل:** إذا لم يكن بينهما جامع، أو لدفع توهم.
- **الربط:** الضمائر، أدوات الربط، الإحالة.

### ٦.٤ الحشو

**علامات الحشو:**
- كلمة لا تضيف معنى.
- تكرار بلا فائدة.
- شرح واضح أصلاً.
- عبارة مترهلة.
- صفة لا تخدم.

**العلاج:** احذف، ثم اقرأ؛ إن بقي المعنى، فالحذف صحيح.

### ٦.٥ العرنجية

| العرنجية | البديل |
| :--- | :--- |
| «قام بزيارة» | «زار» |
| «تم من قبل» | الفاعل المعلوم |
| «من خلال» | «بـ» / «عن طريق» / احذف |
| «على صعيد» | «في» / «على مستوى» / احذف |
| «بالنسبة لـ» | «في» / «لـ» / احذف |
| «بشكل كبير» | «كثيراً» / «جداً» |
| «عملية» | احذف أو سمِّ الفعل |

**قاعدة:** لا تُستبدل كلمة عربية بأخرى أجنبية «لم تشرب روح العربية».

## ٧. اختيار الكلمة

### ٧.١ الدقة

- **الكلمة المعينة** أفضل من المشتركة.
- **الترادف الكاذب:** السقم/المرض، الهضبة/الجبل، الشك/الريب.
- **الفروق الدلالية:** لكل لفظ حدّه.

### ٧.٢ الملاءمة

- **الجزالة** في الحرب والوعيد.
- **الرقة** في الشوق والبعد.
- **العلمية** في البحث.
- **البساطة** في الجمهور العام.

### ٧.٣ الغرابة

- لا تستعمل الغريب الوحشي.
- لا تنقل إلى النثر لفظاً لا يحتمله.
- لا تُكثر الكلمات الطويلة في جملة واحدة.

### ٧.٤ اللفظ والمعنى

- لا تُضحِّ بالمعنى في سبيل السجع أو الجناس.
- لا تُثر اللفظ على المعنى.
- اجعل اللفظ حكاية للمعنى.

### ٧.٥ التنافر

- لا تفصل بين الموصوف وصفته بضمير أجنبي.
- لا تتابع الإضافات.
- لا تُكرر حروفاً ثقيلة.
- اقرأ بصوت مسموع.

## ٨. التدقيق اللغوي

### ٨.١ النحو

- المطابقة: تذكير/تأنيث، عدد، إعراب.
- الترتيب: الفاعل/المفعول، التقديم/التأخير.
- الحذف/الزيادة.
- الضمائر: المرجع واضح.
- أدوات الربط.

> للتفصيل: استدعِ **`arabic-grammar-skill`**.

### ٨.٢ الإملاء

- الهمزات: وصل/قطع، متوسطة/متطرفة.
- الألف اللينة.
- التاء المربوطة/المفتوحة.
- التنوين.
- «مائة/مئة».

### ٨.٣ الترقيم

- النقطة، الفاصلة، الفاصلة المنقوطة، النقطتان.
- الاستفهام، التعجب.
- الاعتراض، القوسان، التنصيص.
- لا مسافة قبل علامة الترقيم.

### ٨.٤ الاتساق

- المصطلح موحد.
- الأسماء موحدة.
- الأرقام موحدة (رقمية/لفظية).
- التاريخ موحد.
- علامات الترقيم موحدة.

## ٩. التحقق

### ٩.١ المراجع

- كل دعوى لها مصدر.
- كل اقتباس له موضع.
- كل رقم له مصدر.
- كل اسم/تاريخ صحيح.
- لا مرجع «من الذاكرة».

### ٩.٢ أنواع الدعاوى

| النوع | ما تتحقق منه |
| :--- | :--- |
| **آية** | السورة والآية |
| **حديث** | المصدر والرقم والحكم |
| **قول عالم** | الكتاب والموضع |
| **إحصاء** | المصدر والتاريخ |
| **اسم/تاريخ** | المصدر |
| **قصة** | المصدر |

### ٩.٣ ما تفعله عند الشك

- لا تُقرّ الدعوى.
- اكتب: `[يحتاج تحققاً]`.
- اسأل الكاتب عن المصدر.
- احذف إن لم يثبت.

> للتفصيل: استدعِ بروتوكول التحقق في **`arabic-khutba-skill`**.

## ١٠. تقرير التحرير

### ١٠.١ القالب

```text
تقرير تحرير
النص: ...
النوع: ...
المستوى: ...
الجمهور: ...
الغرض: ...
الحكم العام: ...

الملاحظات:
| # | الموضع | المشكلة | الخطورة | الاقتراح | السبب |
|---|---|---|---|---|---|
| ١ | ... | ... | عالية/متوسطة/منخفضة | ... | ... |

الخلاصة:
- أهم ثلاث نقاط.
- ما لم يُعدّل ولماذا.
- ما يحتاج قرار الكاتب.
```

### ١٠.٢ درجات الخطورة

| الدرجة | المعنى |
| :--- | :--- |
| **عالية** | تفسد المعنى أو البناء |
| **متوسطة** | تُضعف الوضوح أو الأثر |
| **منخفضة** | تحسين/تجميل |

### ١٠.٣ قواعد التقرير

- لا تُصدر حكماً بلا موضع.
- لا تُصلح بلا سبب.
- لا تُغيّر رأي الكاتب.
- لا تُهمل صوت الكاتب.
- لا تُطالب بما لا يحتاجه النص.

## ١١. عيوب النصوص

| العيب | العلامة | العلاج |
| :--- | :--- | :--- |
| **الركاكة** | ضعف القدرة البيانية | إحكام التركيب |
| **الغموض** | المعنى غير واضح | وضّح الفكرة أولاً |
| **التكلف** | صنعة بلا معنى | احذف الزخرفة |
| **التنافر** | صعوبة النطق | اقرأ بصوت مسموع |
| **الحشو** | كلمات لا تضيف | احذف |
| **التناقض** | دعوى تنقض أخرى | وحّد |
| **الضعف** | عاطفة فاترة | قوِّ الدليل/الصدق |
| **الإحالة** | مبالغة مستحيلة | اجعلها ممكنة |
| **الابتذال** | عبارات مستهلكة | جدّد |
| **الأدب اللفظي** | زخرفة بلا مضمون | احذف |
| **التقليد** | تراكيب محفوظة | جدّد |

## ١٢. قبل/بعد

### نموذج ١: حشو

**قبل:**
> «قام الفريق الذي تم تشكيله من قبل الإدارة بدراسة الموضوع دراسة مستفيضة من أجل الوصول إلى النتائج.»

**بعد:**
> «درست اللجنة الموضوع، ووصلت إلى النتائج.»

**السبب:** حذف العرنجية والحشو، وأعاد الفاعل المعلوم.

### نموذج ٢: جملة طويلة

**قبل:**
> «وبما أن المشروع الذي أطلقته الوزارة في العام الماضي والذي يهدف إلى تحسين الخدمات في المناطق النائية قد واجه صعوبات مالية فإنه يحتاج إلى مراجعة شاملة.»

**بعد:**
> «أطلقت الوزارة المشروع العام الماضي لتحسين الخدمات في المناطق النائية. وقد واجه صعوبات مالية، فهو يحتاج إلى مراجعة شاملة.»

**السبب:** تقسيم الجملة، وتقديم المعلوم.

### نموذج ٣: فقرة بلا وحدة

**قبل:**
> «التعليم مهم. وقد زرت المدينة القديمة. والجامعة تحتاج إلى تمويل. وكان الطقس جميلاً.»

**بعد:**
> «التعليم مهم، والجامعة تحتاج إلى تمويل. أما المدينة القديمة والطقس فحديث آخر.»

**السبب:** فصل الأفكار، وحذف ما لا يخدم.

### نموذج ٤: تكلف

**قبل:**
> «سعى فسعى فسعى، فما نال إلا ما نال.»

**بعد:**
> «سعى طويلاً، فما نال إلا ما نال.»

**السبب:** حذف التكرار.

### نموذج ٥: تنافر

**قبل:**
> «وقبر حرب بمكان قفر / وليس قرب قبر حرب قبر.»

**بعد:**
> «قبر حرب في مكان قفر، وليس قرب قبره قبر.»

**السبب:** تخفيف التنافر، مع حفظ المعنى.

## ١٣. قائمة التدقيق النهائية

### أولاً: البنية
- [ ] أطروحة واضحة.
- [ ] بناء يخدمها.
- [ ] أقسام مترابطة.
- [ ] مقدمة/خاتمة.
- [ ] لا حشو.

### ثانياً: الفقرة
- [ ] فكرة واحدة.
- [ ] جملة موضوعية.
- [ ] دعم.
- [ ] ربط.
- [ ] انتقال.

### ثالثاً: الجملة
- [ ] واضحة.
- [ ] ليست طويلة.
- [ ] الترتيب سليم.
- [ ] لا حشو.
- [ ] لا عرنجية.

### رابعاً: الكلمة
- [ ] دقيقة.
- [ ] مناسبة.
- [ ] غير غريبة.
- [ ] غير مبتذلة.
- [ ] لا تنافر.

### خامساً: الميكانيكا
- [ ] نحو سليم.
- [ ] إملاء سليم.
- [ ] ترقيم سليم.
- [ ] اتساق المصطلح.
- [ ] اتساق الأرقام.

### سادساً: المراجع
- [ ] كل دعوى لها مصدر.
- [ ] كل اقتباس له موضع.
- [ ] الأرقام/الأسماء/التواريخ صحيحة.
- [ ] لا مرجع من الذاكرة.

### سابعاً: الصوت
- [ ] صوت الكاتب محفوظ.
- [ ] لا إعادة كتابة صامتة.
- [ ] كل تعديل مشروح.

## ١٥. أوامر التشغيل

| إذا قال المستخدم... | فافعل |
| :--- | :--- |
| «حرّر النص» | تقرير + تعديل بطبقات |
| «دقّق» | نحو/إملاء/ترقيم/اتساق |
| «راجع البنية» | أطروحة/بناء/فقرات |
| «قلّل الحشو» | احذف، وبيّن ما حذفت |
| «حسّن الأسلوب» | جملة/كلمة/إيقاع |
| «تحقق من المراجع» | كل دعوى + مصدر |
| «ما رأيك في النص؟» | تقرير نقدي منصف |
| «أعد كتابته» | حافظ على الصوت، وبيّن التغييرات |
| «هل هذا جيد؟» | معايير: صدق/جمال/أثر/أصالة/وحدة |
| «لا تُغيّر المعنى» | التزم، واقترح فقط |
