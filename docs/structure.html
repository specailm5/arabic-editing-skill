٤. المقدمة

  • جذب الانتباه.
  • تحديد الموضوع.
  • بيان الأطروحة.
  • بيان الخطة.

محاذير: لا تُطل، ولا تبدأ باعتذار.

٥. العرض

  • كل قسم فكرة واحدة.
  • كل فكرة دليلها.
  • الترتيب للأهم للقارئ.
  • الانتقالات واضحة.

٦. الخاتمة

  • تلخيص.
  • تأكيد الأطروحة.
  • دعوة/توصية.
  • فتح أفق.

محاذير: لا فكرة جديدة، ولا إطالة.
