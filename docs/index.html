ما هي هذه المهارة؟

مهارةٌ تُعلِّمُ وكلاءَ الذكاء الاصطناعي أن يحرّروا النص العربي وينقدوه ويدققوه، لا أن يعيدوا كتابته بصمت. تجمع بين الأسلوب وأصول النقد الأدبي لأحمد الشايب، ومعجم الصواب اللغوي لأحمد مختار عمر.

أربع قواعد: صوت الكاتب أولاً، أقل تدخل، كل تعديل بسببه، التحقق قبل التسليم.

ما يفسد النص

  • الركاكة: ضعف القدرة البيانية.
  • الغموض: المعنى غير واضح.
  • التكلف: صنعة بلا معنى.
  • التنافر: صعوبة النطق.
  • الحشو: كلمات لا تضيف.
  • التناقض: دعوى تنقض أخرى.
  • الابتذال: عبارات مستهلكة.
  • الأدب اللفظي: زخرفة بلا مضمون.

لماذا هذه المهارة؟

لأن التحرير ليس إعادة كتابة. المهارة تمنع الوكيل من تغيير صوت الكاتب بلا إذن، ومن الحكم بلا موضع، ومن تصحيح رقم أو مرجع من الذاكرة، ومن الاكتفاء بفاصلة وترك البنية مبعثرة.

For English readers

An open agent skill for Arabic editing, critique and proofreading. It edits in layers — structural, paragraph, line, copy, proof, fact-check — produces an editorial report with severity and reasons, preserves the author's voice, and refuses silent rewrites. Works with Claude Code, Codex, Antigravity and VS Code agent harnesses.

المراجع

«الأسلوب» و«أصول النقد الأدبي» لأحمد الشايب، و«معجم الصواب اللغوي» لأحمد مختار عمر. إقرار بالفضل: هذه المهارة صياغة تعليمية مستقلة لمبادئ هذه الكتب، مع نقل قواعد وأمثلة بإسنادها إلى أبوابها؛ ولا يتضمّن المستودع نسخاً كاملة من الكتب.

التحرير والنقد — مهارة مستخلَصة من الأسلوب وأصول النقد الأدبي ومعجم الصواب اللغوي.
